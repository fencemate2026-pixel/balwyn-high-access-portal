This demonstration is not connected to a school network or the RJL service server.

Identity badge

Issue a QR pass

Each pass carries a signed token bound to the hirer, the gates and the window. Present it to the reader at the gate and it opens — outside the window the same code is refused and the attempt is logged. Revoking a booking kills every pass issued under it immediately.
